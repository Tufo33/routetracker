# RouteTracker 🚚

A logistics dashboard for managing delivery routes, built with real-world experience as a mail carrier.

## Features
- ✅ Full CRUD Dashboard (Create, Read, Update, Delete)
- ✅ Driver management with dropdown selection
- ✅ Route filtering by status (On the way, Planned, Completed)
- ✅ Search by driver name
- ✅ Sort by stops and packages
- ✅ Pagination with page navigation
- ✅ Toast notifications
- ✅ Responsive design (mobile-friendly)
- ✅ Jest unit tests

## Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Node.js
- **Database:** PostgreSQL
- **Testing:** Jest, ts-jest
- **Version Control:** Git, GitHub

## Getting Started

### Prerequisites
- Node.js
- PostgreSQL (Port 5433)

### Installation
```bash
git clone https://github.com/Tufo33/routetracker
cd routetracker
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
